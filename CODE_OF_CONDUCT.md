# Code of Conduct

This is a learning project. We want it to be a place where beginners and experts can ask questions, make mistakes, and improve the course.

## Expected behavior
- Be respectful and assume good faith. Critique code, lessons, and ideas, not people.
- Welcome questions from learners at any level.
- Keep security discussion within the project's rules: training binaries built in this repo, and software you are authorized to analyze.

## Unacceptable behavior
- Harassment, insults, discrimination, or personal attacks.
- Sharing someone's private information.
- Posting malware, stolen credentials, or requests for help bypassing protections on third-party software.

## Enforcement
Maintainers may edit or remove contributions, and block participants, for behavior that breaks these rules. Report concerns by opening a private security advisory (Security tab, "Report a vulnerability") or by contacting the repository owner on GitHub.
