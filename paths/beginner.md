# Path: Absolute Beginner

For: no C and no assembly, possibly little terminal experience.
Route: P0 (C and Memory Primer), then every core module in order. Electives after module 15 if interested.
Estimate: ~235 hours (see `README.md`).

## Confirmation quiz (after P0, before module 00)
1. Predict the output of a 15-line program with a loop and an `if`.
2. Write a function that sums an array of ints given a pointer and a length.
3. Explain, in one sentence each, a variable, a type, an address, and a function call.
4. Use the terminal to create a folder, compile a file with `clang` or `gcc`, and run it.
5. Explain what `#include <stdio.h>` does.

Missing three or more: repeat the weak parts of P0.

## Tutor adjustments
- Context-first by default: open each module with its Context line from `goals.md`.
- Smaller steps: one command per step, prediction before every command.
- Revisit C at every new construct (the "C through the lens of memory" rule in `AGENTS.md`).
- No skipping in Phase A. From Phase B onward, normal skip rules apply.
- Expect Phase A and B to take longest; celebrate the module 04 decompiler milestone as the first "I can read a binary" moment.
